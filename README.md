# Monisha's Portfolio

A responsive, dark-purple portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — the content and sections
- `style.css` — colors, layout, responsive styles, and animations
- `script.js` — mobile menu, navigation highlighting, and placeholder-link feedback
- `resume.pdf` — add your own resume PDF here if you want the download link to work

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

You do not need to install Python or any packages.

## Personalize before publishing
1. Search `index.html` for `your.email@example.com` and replace it with your real professional email.
2. Replace each social link with your actual GitHub and LinkedIn profile URLs. Search for `data-placeholder-link`.
3. Check that your project description accurately reflects your contribution and tools used.
4. Add your internship organization, role, dates, and work completed.
5. Add your paper presentation title, event, and date.
6. If you want the resume download button to work, copy your PDF into this folder and name it `resume.pdf`.
7. Review the skill descriptions and progress bars so they match your current ability.
8. Test the page on mobile and desktop.

## Publish using GitHub Pages
1. Create a GitHub repository named `monisha-portfolio` (or another name you prefer).
2. Upload the files from this folder to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, select deployment from a branch, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish and open the website URL shown in that section.

The exact GitHub interface may change over time. Never upload passwords, private keys, or confidential data.
